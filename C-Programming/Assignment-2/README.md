# C Programming - Assignment 2

Questions 01-40, each in a separate source file. Compile and run one question at a time. These C programming exercises use the original .cpp filenames from Dev-C++.

Example:

    g++ "Question 39.cpp" -o question39
    ./question39

Question 40 is the Mini Shopping Management System, saved as C source. Compile and run with:

    gcc -std=c11 "Question 40.c" -o question40
